# FERDA_v2

FERDA is my version of simple LocoNet® throttle hevily inspired by FREMO FREDi. This version utilize extra cheap MCU CH32V203. Trogram is developed using Arduino IDE + WCH [Arduino core](https://github.com/openwch/arduino_core_ch32).

## Hardware
Ferda is oriented to be effective in network communication. To achieve this, it utilize capacitor for survive disconections.
